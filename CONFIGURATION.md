# Local configuration

Set the variables listed in `.env.example` in your process environment before starting the application. If the project uses dotenv, you can copy the example to a local `.env` file and fill in the values. Other projects require exported environment variables or their existing environment-file setup.

Real environment files, credential JSON files, uploaded files, installed dependencies, and generated output are excluded from this source snapshot. Supply any required service credentials locally. Original commit history is not included.
